## 📋 Overview

This is the frontend application for **HealthLink 360**, a comprehensive healthcare management platform. Built with React 19 and Vite, it provides role-based dashboards for patients and doctors with modern UI/UX, animations, and real-time health tracking.

## ✨ Features

### 🩺 Patient Features

#### 📊 Health Dashboard
Central hub displaying current vitals (BMI, Blood Pressure, Sugar, Heart Rate), recent health records with AI analysis results, quick action buttons for adding logs and connecting with doctors, and an AI health assistant card for instant health queries.

#### 📄 Document Upload & AI Analysis
Drag-and-drop file upload supporting PDF and image formats for medical reports. Automatic AI-powered extraction of test results with normal range comparison, status classification, disease detection, and personalized health recommendations.

#### 🎯 Goal Tracking System
Create health goals with multiple types (increase, decrease, maintain, range). Set custom parameters with target values and deadlines. Track progress with visual progress bars and percentage indicators. Add milestones with dates, values, and notes to monitor journey.

#### 🤖 AI Health Assistant
Conversational AI interface powered by Google Gemini. Context-aware responses using patient's health logs and goals data. Get personalized health advice, answer medical queries, and receive lifestyle recommendations.

#### 📅 Google Calendar Integration
OAuth-based Google Calendar connection. Automatic sync of health goal reminders and deadlines. Create, view, and delete calendar events directly from the app. Visual calendar view with upcoming health-related events.

#### 📋 Appointments Management
Request appointments with connected doctors. View appointment status (pending, confirmed, completed, cancelled). Receive notifications for appointment updates. Track upcoming and past appointments.

#### 📝 Doctor Notes
View clinical notes sent by connected doctors. Reply to notes with secure messaging. Track unread notes with badge notifications. Chronological note history with timestamps.

#### 🔗 Doctor Connection
Search and connect with doctors using email. Send connection requests with pending/accepted status tracking. Share health logs and goals with connected doctors. Control sharing visibility per doctor.

#### 📈 Health Trends Visualization
Interactive charts showing health parameter trends over time. Compare multiple parameters on single timeline. Filter by date range and parameter type. Visual indicators for improvements and concerns.

---

### 👨‍⚕️ Doctor Features

#### 🏠 Doctor Dashboard
Overview of all connected patients with quick stats. Incoming connection requests with accept/reject actions. Today's appointments list with status indicators. Pending appointment requests from patients.

#### 👥 Patient Management
Complete list of connected patients with search and filter. View patient's shared health logs with AI analysis. Access patient's health goals and progress. Quick navigation to detailed patient view.

#### 📋 Clinical Notes System
Create clinical notes for specific patients. Categorize notes by type (general, prescription, follow-up, lab-results). View patient replies and maintain conversation thread. Track read/unread status.

#### 🤖 AI Patient Summary
Generate comprehensive AI-powered patient health summary. Analyzes all shared health logs, goals, and notes. Provides risk assessment, trends, and recommendations. One-click generation with detailed markdown output.

#### 📅 Appointment Scheduling
Create appointments for patients with date, time, and reason. Respond to patient appointment requests (accept/reject with reason). Mark appointments as completed. View complete appointment history.

#### 👤 Profile Management
Complete doctor profile setup with speciality, clinic name, experience, and qualification. Update profile information anytime. Profile completion required before accessing dashboard.
